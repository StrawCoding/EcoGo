EcoGo

Google Maps 路線引擎 · Ionex／Gogoro／加油站間隔選站 · 一鍵開啟 Maps。

Google Maps API

需啟用：Maps JavaScript API、Places API、Directions API。金鑰僅存本機 localStorage，不會上傳。

交通模式

汽車模式：Google Maps Directions DRIVING。

每隔幾公里找一站
加油站
每隔幾公里找一站

例：Ionex 設 40 → 沿 Google 路線約每 40km 選最靠近的站，再組成可直開的 Maps 導航連結。

請先載入 Google Maps API Key。
